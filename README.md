# 🏦 Midas

Project repository for the **J.P. Morgan Chase & Co. Advanced Software Engineering Virtual Experience** on [Forage](https://www.theforage.com/).

## 📘 Overview
This project simulates components of JPMC’s internal trading platform **Midas**, focusing on real-time data processing and visualization using modern software engineering practices.

## 🚀 Key Highlights
- **Developed and containerized** a data visualization dashboard to simulate live financial data updates.  
- **Integrated Kafka-based data streaming** and backend APIs to process and visualize real-time transaction data.  
- **Implemented Git-based version control** and followed **Agile workflows** to emulate enterprise-level development practices.

## 🛠️ Tech Stack
**Java** · **React** · **Docker** · **Apache Kafka** · **Git**
