# Midas Core System

The Midas Core is a critical component of the Midas system responsible for **receiving, validating, and recording financial transactions**. It integrates with various external resources, including **Kafka, SQL Database, and a REST API**. This project uses **Spring Boot** for building a robust backend application.

## 🚀 Getting Started

### Prerequisites
- **Java 17** (JDK)
- **Maven** (Included with the project via `mvnw`)
- **IDE** (Recommended: IntelliJ IDEA)
